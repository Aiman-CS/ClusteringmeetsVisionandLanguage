# Annotation codebook

All human fields start blank. Use yes/no/uncertain for complete instrument, part, representation, placeholder, plausible source HS, and recommended exclusion. A flag is only a sampling rule; titles can match innocently (e.g. an entire flute mentioning embouchure). Low entropy or saturation does not prove a placeholder or drawing. Multiple HS concepts can be compatible. Assess images and source evidence; do not infer corrections from titles alone.

If possible same-object views are confirmed, enter the partner image ID in same_object_as_image_id; similar instrument types are not necessarily the same specimen. Record reviewer, date and notes. Do not edit source columns. No annotations are automatically applied to labels, exclusions or scores. Maintain a reviewed copy and an explicit new dataset version for any later curation.

Sampling: 30 possible-pair images, 30 museum-random, 30 HS1-stratified, 30 large/small-cluster, 30 lexical/low-entropy/low-saturation candidates, 30 missing/multiple-HS. Disjoint selection in that order, seeded 20261102. Prior selections can change stratum quotas; actual coverage is saved. This enriched review set is not a representative error-rate sample.
